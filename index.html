系统学习笔记

这一页先完成授课：把 FLUTD 当作“临床问题集合”来理解，而不是直接背一个疾病名。

1. 什么是 FLUTD

FLUTD 是 Feline Lower Urinary Tract Disease 的缩写，指影响猫膀胱和尿道的一组疾病或临床问题。它不是单一诊断，真实门诊入口通常是“猫频繁进猫砂盆”“尿少”“血尿”“乱尿”“舔尿道口”。

对新手来说，第一步不是马上猜病因，而是判断这只猫是否存在尿道阻塞风险。

2. 先定位：下泌尿道到底是哪一段

下泌尿道主要指膀胱和尿道。膀胱负责储尿，尿道负责把尿排出体外。肾脏和输尿管属于上泌尿道，但严重尿道阻塞会让压力向上游传递，并造成肾小球滤过下降、代谢废物潴留和电解质异常，所以尿闭病例仍要看肾功能与电解质。

膀胱受刺激

常表现为尿频、每次尿量少、尿痛、血尿和乱尿；动物可能仍能排出尿。

尿道流出受阻

频繁用力但无尿或只有几滴，膀胱可能大、紧、疼痛；公猫尤其需要快速排查。

3. 为什么先排尿闭

尿道阻塞是 FLUTD 中最需要快速识别的急症。完全阻塞时，尿液不能排出，肾脏排毒和水电解质平衡会迅速受到影响，可能发展为危及生命的状态。

  • 公猫或已绝育公猫风险更高，因为尿道更长更窄。
  • 无尿、极少尿、频繁痛苦蹲猫砂盆，要优先怀疑阻塞。
  • 呕吐、沉郁、虚弱、食欲废绝，提示问题可能已经不只是局部尿路不适。
  • 触诊到大而紧张的疼痛膀胱强烈支持阻塞，但膀胱大小仍需结合病程、是否部分阻塞和体检整体判断。

4. 先把症状术语分清

尿频 Pollakiuria排尿次数增加，但每次量通常很少，常指向下泌尿道刺激。
排尿困难 Dysuria / Stranguria排尿疼痛、费力或长时间蹲尿，要继续确认到底排出了多少。
血尿 Hematuria可见或镜下红细胞增加，说明出血存在，但不能单凭血尿判断感染。
异位排尿 Periuria在猫砂盆外排尿，可能由疼痛、紧迫感、砂盆厌恶或环境压力引起。
少尿 / 无尿尿量明显减少或没有尿。新手要先区分“产生得少”与“产生了但排不出”。
多尿 Polyuria总尿量增加，尿团通常变大；与“频繁但每次几滴”的尿频不是同一个概念。
表现 临床含义 新手提醒
频繁进猫砂盆、每次尿量少 下泌尿道刺激、疼痛或排尿受阻 先确认有没有真实尿团
血尿、尿痛、嚎叫 膀胱或尿道炎症、结石、损伤等 血尿不等于细菌感染
乱尿、舔尿道口 疼痛、不适、行为改变或环境压力相关 不要直接归因于“报复主人”
无尿、呕吐、沉郁 疑似阻塞或全身风险 按急症升级处理

6. 三个最容易混淆的概念

FIC 是排除性方向

猫特发性膀胱炎没有一个单项化验可以“验出来”。病史、尿检和必要影像排除尿石、感染等明确原因后，才形成工作诊断；压力与环境因素是重要线索，但“有应激”本身也不能单独确诊。

结晶不等于结石

尿沉渣见到结晶只说明尿中出现了晶体。是否存在有临床意义的尿石，要结合新鲜样本、结晶类型、症状和影像；样本放置过久还可能出现体外结晶。

血尿/白细胞不等于感染

FIC、尿石和采样创伤都可能造成红细胞或炎症细胞增加。细菌性膀胱炎需要结合采样方式、沉渣和培养，不能因为试纸“潜血阳性”就开抗菌药。

尿液浓缩不等于肾功能正常

尿比重反映的是这份尿液的浓缩程度。解读时要同时看水合状态、血液肾指标、用药和疾病背景，不能用单个尿比重替代完整肾功能判断。

7. 尿道阻塞为什么会变成全身急症

尿排不出去膀胱内压力升高，动物持续疼痛和用力排尿。
滤过下降尿路压力上升后，肾脏清除代谢废物的能力受影响。
氮质血症与高钾尿素氮、肌酐可能升高，钾潴留可影响心脏电活动。
全身失代偿可出现呕吐、沉郁、脱水、低体温、虚弱或心律异常。

因此，疑似阻塞时的优先级是先评估稳定性和解除危险，而不是先花时间把 FIC、结石或尿道栓分得非常精细。

8. 诊断路径

主诉尿频、尿痛、血尿、乱尿、舔尿道口。
急症分层先问能否排尿，再摸膀胱和看全身状态。
基础检查体检、尿检；疑似尿闭时加血检、电解质、肾功能。
病因鉴别FIC、尿石、尿道栓、感染、环境压力。
长期管理饮水、湿粮、体重、猫砂盆资源、压力源和复查。

9. 初诊检查与采样前误差

  • 尿检：确认尿液浓缩程度、pH、血尿、沉渣、结晶、细胞等。
  • 血检和生化：评估全身状态，尤其是脱水、肾功能和炎症线索。
  • 电解质：疑似尿闭时很关键，用来评估急症风险。
  • 影像：用于评估结石、膀胱状态和其他结构性问题。
  • 尿培养：不是所有猫都要做，但老年、复发、复杂或怀疑感染时有价值。
先记采样方式自然排尿、导尿和膀胱穿刺的污染风险不同；培养结果必须和采样方式一起解释。
尽量检查新鲜尿放置时间和保存条件会改变细胞、管型、pH、细菌数量，并可能造成体外结晶。
穿刺也会造成血尿膀胱穿刺可能引入少量红细胞，所以显微镜血尿仍需结合肉眼尿色、症状和采样过程。
试纸不能包办全部试纸、尿比重和沉渣解决的问题不同；细菌感染确认尤其不能只看试纸。

10. 怎样写出合格的工作判断

新手不要急着写“确诊 FIC”或“确诊感染”。先用四句话把证据链写完整：

  1. 危险分层：目前是否能排尿，膀胱和全身状态是否支持阻塞急症。
  2. 主要异常：症状、体检和化验中真正异常的项目是什么。
  3. 当前支持方向：这些异常更支持炎症、尿石、感染还是阻塞后的全身影响。
  4. 仍缺证据：哪些诊断尚不能成立，下一项检查是为了回答什么问题。
示例：该猫仍能排尿，膀胱不大，全身状态稳定；尿检主要表现为血尿，未见明确脓尿和细菌证据。当前支持非阻塞性下泌尿道炎症，FIC 可列为工作方向，但仍需结合病史及必要影像排除尿石，现有结果不足以诊断细菌性膀胱炎。

11. 复发管理

FLUTD 不是症状缓解就结束。对于 FIC 或复发病例，要把长期管理讲成“降低刺激和压力、增加尿液稀释、减少复发机会”。

  • 增加饮水和湿粮比例，减少尿液过度浓缩。
  • 控制体重，增加运动和玩耍。
  • 猫砂盆数量充足，常用原则是猫数 + 1。
  • 猫砂盆放在安静、安全、容易进入的位置，并保持清洁。
  • 减少突然换粮、搬家、多猫冲突等压力源。
  • 提供躲藏、攀爬、休息和捕猎模拟机会。

临床路径图

这个图是新手接诊“猫尿频、尿痛、乱尿”时的基础路径。核心不是背答案，而是先把危险分层做对。

节点 1：第一判断

  • 先问有没有明确尿团。
  • 再问每次尿量，是正常、小尿团、几滴，还是完全没有。
  • 主人说“不确定”时，不能按低风险处理。

节点 2：急症信号

  • 公猫、无尿或极少尿、痛苦蹲猫砂盆。
  • 呕吐、沉郁、虚弱、食欲废绝。
  • 膀胱大、硬、紧张疼痛。

节点 3：基础检查

  • 体检和膀胱触诊决定是否先升级。
  • 尿检是非阻塞病例的基础入口。
  • 疑似尿闭时，血检、电解质和肾功能优先级上升。

节点 4：复发管理

  • 不要只讲症状缓解，要讲为什么会复发。
  • 把饮水、湿粮、体重、猫砂盆资源和压力源一起讲。
  • 复查计划要根据病因和复发风险来安排。

新手常见偏差

  • 把频繁蹲猫砂盆当便秘。
  • 把血尿直接等同于细菌感染。
  • 只讲开药，不解释检查目的。
  • 只处理当次症状，不讲长期管理。

化验报告解读：先建立固定读单顺序

不要从标红项目直接跳到诊断。先确认病例状态和样本质量，再识别异常、组合证据、排除危险，最后才形成工作判断。下方报告为教学模拟数据，参考区间仅供练习，真实病例必须以本院仪器、采样方式和上级医生判断为准。

1. 看病例性别、年龄、能否排尿、膀胱和全身状态。化验单永远不能脱离病猫。
2. 看样本采样方式、时间、保存、是否溶血或污染，先判断结果能不能信。
3. 找危险疑似阻塞时先看钾、肾指标和酸碱/心电风险，不先纠结结晶类型。
4. 组证据把尿比重、pH、红白细胞、细菌、结晶和影像放在一起解释。
5. 写结论分别写“支持什么、不能证明什么、下一步回答什么问题”。

尿检：三层阅读法

  • 物理层：颜色、透明度、尿比重。尿比重说明浓缩程度，但要结合水合状态和血液肾指标。
  • 化学层：pH、潜血、蛋白、葡萄糖、酮体等。猫尿试纸部分项目可靠性有限，不能脱离沉渣。
  • 沉渣层：红细胞、白细胞、上皮细胞、细菌、结晶和管型。先问是否新鲜、怎样采到。
关键限制：血尿和脓尿都不是感染特异指标；自然排尿样本见少量细菌可能是污染，尿培养以膀胱穿刺样本更有解释力。

生化和电解质：先看急症风险

  • 钾：阻塞时可能升高，严重异常会影响心脏电活动；要结合心率、心电和患者稳定性。
  • 肌酐/尿素氮：升高可见于阻塞后的肾后性氮质血症，也会受脱水和既往肾病影响。
  • 磷与酸碱：可随严重或持续阻塞出现异常，帮助判断全身代谢影响。
  • 总蛋白/红细胞压积：可提供脱水线索，但仍要回到体检综合判断。
关键限制：肾指标正常不能单独排除早期或部分阻塞；肾指标升高也不能脱离排尿史直接等同于原发肾病。

影像与培养：回答不同问题

  • X 光：适合寻找多数不透射线结石并观察位置、数量和大小，但不是所有结石都同样显影。
  • 超声：可观察膀胱内容物、壁和部分结构异常，但尿道远端评估有限。
  • 培养：回答“是否存在有意义的细菌生长”，样本应尽量在抗菌药前获取。
  • 药敏：回答“分离菌对哪些药物敏感”，不能由尿频或试纸结果替代。
关键限制：影像未见结石不等于没有 FLUTD；培养阴性也不排除 FIC、结石或其他非感染性病因。
